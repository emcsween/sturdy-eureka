# sturdy-eureka

This repository contains an example LaTeX article demonstrating various features of the LaTeX typesetting system.

## Contents

- `article.tex` - A complete example LaTeX article with:
  - Document structure (sections, subsections)
  - Abstract and introduction
  - Mathematical equations and formulas
  - Tables
  - References and bibliography
  - Cross-referencing

## Compiling the Article

To compile the LaTeX article into a PDF, you can use:

```bash
pdflatex article.tex
```

Or use your preferred LaTeX distribution (TeX Live, MiKTeX, etc.).
